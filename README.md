# Wiki-Medizininformatik

Technische Dokumentation zu Medizininformatik, Medizintechnik, Krankenhaus-IT und Vernetzung.

## Anmeldung

Das Wiki ist hinter einer Login-Seite geschützt. Es gibt zwei Zugänge:

| Rolle | Benutzername | Passwort | Rechte |
| --- | --- | --- | --- |
| Admin | `admin` | `Admin2026` | Wiki, Verwaltung, Nutzer anlegen, interne Hinweise |
| Listener | `listener` | `Listener2026` | Wiki lesen, keine Verwaltungsfunktionen |

- Login: `login.html`
- Admin-Bereich: `admin.html` (nur nach Admin-Anmeldung)

Listener werden vom Admin-Bereich auf die Startseite zurückgeführt. Zusätzliche Konten können im Admin-Bereich lokal im Browser angelegt werden.

Die aktuelle Demo-Anmeldung läuft clientseitig (ohne Server). Für den späteren Produktivbetrieb sollte eine echte Benutzerverwaltung ergänzt werden.
