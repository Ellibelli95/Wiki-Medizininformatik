1. Was ist CSS?

AspektBeschreibung
DefinitionCSS (Cascading Style Sheets) ist eine Stylesheet-Sprache zur Beschreibung der visuellen Darstellung von HTML-Dokumenten.
ZweckTrennung von Inhalt (HTML) und Gestaltung (CSS), wodurch Layout-Änderungen zentral und ohne Eingriff in die Dokumentstruktur möglich werden.
StandardisierungCSS wird vom W3C als Sammlung modularer Spezifikationen (CSS3-Module) weiterentwickelt, z. B. für Selektoren, Flexbox oder Grid.

2. Historische Entwicklung

VersionMerkmal
CSS1 (1996)Grundlegende Eigenschaften für Schrift, Farbe und einfaches Boxlayout.
CSS2/2.1 (1998/2011)Erweiterte Positionierung, Medientypen und verbesserte Kaskadenregeln.
CSS3 (modular, seit ca. 2011)Aufteilung in unabhängige Module (u. a. Flexbox, Grid, Animations, Media Queries), wodurch einzelne Bereiche eigenständig weiterentwickelt werden können.

3. CSS-Syntax und Selektoren

SelektortypBeispielBedeutung
Elementselektorp { }Wählt alle Elemente eines bestimmten Typs aus.
Klassenselektor.hinweis { }Wählt alle Elemente mit der Klasse „hinweis“ aus.
ID-Selektor#kopf { }Wählt genau ein Element mit der ID „kopf“ aus.
Kombinatorennav a, ul > liWählen Elemente anhand ihrer Position im Dokumentbaum aus (Nachfahre, direktes Kind).
Pseudo-Klassen:hover, :focusWählen Elemente abhängig von einem Zustand aus.

4. CSS in HTML einbinden

MethodeBeschreibungEmpfehlung
InlineÜber das style-Attribut direkt am ElementNur für punktuelle Ausnahmen; erschwert Wartung und Kaskade
InternInnerhalb eines <style>-Blocks im <head>Für einzelne, in sich geschlossene Seiten geeignet
ExternÜber <link rel="stylesheet"> eingebundene Datei (siehe Kapitel „HTML“, Abschnitt 6)Standardfall für produktive Projekte; ermöglicht Caching und Wiederverwendung

5. Kaskade und Spezifität

FaktorBeschreibung
KaskadeBei widersprüchlichen Regeln entscheiden Quelle (Browser-, Autoren-, Nutzer-Stylesheet), Spezifität und Reihenfolge im Dokument über die angewendete Regel.
SpezifitätID-Selektoren wiegen schwerer als Klassenselektoren, diese wiederum schwerer als reine Elementselektoren.
!importantÜberschreibt die normale Spezifitätsberechnung; sollte sparsam eingesetzt werden, da es die Wartbarkeit erschwert.
VererbungBestimmte Eigenschaften (z. B. color, font-family) werden automatisch an Kindelemente weitergegeben, sofern nicht überschrieben.

6. Das Box-Modell

Das CSS-Box-Modell: Jedes Element besteht aus Inhalt, Innenabstand (Padding), Rahmen (Border) und Außenabstand (Margin).
BestandteilBeschreibung
ContentDer eigentliche Inhalt des Elements (Text, Bild, verschachtelte Elemente).
PaddingInnenabstand zwischen Inhalt und Rahmen.
BorderSichtbarer oder unsichtbarer Rahmen um Inhalt und Padding.
MarginAußenabstand zu benachbarten Elementen.
box-sizingBestimmt, ob Breiten-/Höhenangaben nur den Content (content-box) oder zusätzlich Padding und Border (border-box) einschließen.

7. Positionierung und Floating

WertBeschreibung
staticStandardverhalten; das Element folgt dem normalen Dokumentfluss.
relativeVerschiebung relativ zur eigentlichen Position, ohne den Fluss der übrigen Elemente zu beeinflussen.
absolutePositionierung relativ zum nächsten positionierten Vorfahren; das Element wird aus dem normalen Fluss entfernt.
fixedPositionierung relativ zum Browser-Viewport; bleibt beim Scrollen an derselben Bildschirmposition.
floatHistorische Technik zur Umfließung von Elementen (z. B. Bildern), heute größtenteils durch Flexbox/Grid abgelöst (siehe Kapitel 9).

8. Responsive Webdesign mit Media Queries

AspektBeschreibung
Media QueryCSS-Regel, die abhängig von Eigenschaften des Ausgabegeräts (z. B. Viewport-Breite) angewendet wird, etwa @media (max-width: 768px) { }.
Mobile FirstEntwurfsprinzip, bei dem zunächst für kleine Bildschirme gestaltet und die Darstellung für größere Viewports schrittweise erweitert wird.
Viewport-Meta-Tag<meta name="viewport" content="width=device-width, initial-scale=1.0"> sorgt dafür, dass mobile Browser die Seite nicht künstlich verkleinern.
Bedeutung im KlinikumfeldKlinische Web-Clients werden häufig sowohl auf stationären Arbeitsplätzen als auch auf mobilen Visitenwagen/Tablets genutzt – responsive Gestaltung ist daher Standardanforderung.

9. Flexbox und Grid

TechnikEinsatzbereichKernkonzept
FlexboxEindimensionale Anordnung (Zeile oder Spalte)display:flex mit Eigenschaften wie justify-content und align-items zur flexiblen Verteilung von Platz
CSS GridZweidimensionale Layouts (Zeilen und Spalten gleichzeitig)display:grid mit grid-template-columns/-rows zur präzisen Rasteranordnung
Verhältnis zu älteren Techniken—Beide Techniken lösen die früher übliche, fehleranfällige Umsetzung komplexer Layouts über float ab.

10. Präprozessoren und Frameworks

WerkzeugBeschreibung
SASS/SCSSCSS-Präprozessor mit Variablen, Verschachtelung, Mixins und Funktionen; wird zu reinem CSS kompiliert.
LESSÄhnlicher Präprozessor mit vergleichbarem Funktionsumfang, JavaScript-basiert kompilierbar.
CSS-Frameworks (z. B. Bootstrap)Fertige Klassenbibliotheken für Raster, Komponenten und responsive Layouts, die die Entwicklungszeit deutlich verkürzen können.

11. CSS in der Medizin-IT

AspektBeschreibung
Responsive DashboardsÜberwachungs- und Verlaufsdaten aus PDMS/KIS werden über responsive Layouts auf unterschiedlichsten Endgeräten lesbar dargestellt.
Konsistentes ErscheinungsbildZentral gepflegte Stylesheets sorgen für ein einheitliches, wiedererkennbares Erscheinungsbild über verschiedene Fachanwendungen hinweg.
ZugänglichkeitAusreichende Farbkontraste und skalierbare Schriftgrößen unterstützen die Lesbarkeit unter klinischen Lichtverhältnissen.
