1. Was ist HTML?

AspektBeschreibung
DefinitionHTML (HyperText Markup Language) ist eine textbasierte Auszeichnungssprache zur Strukturierung von Inhalten im World Wide Web.
FunktionsweiseInhalte werden durch Elemente (Tags) ausgezeichnet, die deren Bedeutung und Struktur beschreiben – nicht deren visuelle Darstellung, die durch CSS erfolgt.
StandardisierungHTML wird vom World Wide Web Consortium (W3C) bzw. der WHATWG als „living standard“ weiterentwickelt.
Rolle im Web-StackHTML bildet zusammen mit CSS (Gestaltung) und JavaScript (Verhalten) die drei grundlegenden Client-Technologien des Web.

2. Historische Entwicklung

VersionWesentliche Neuerung
HTML (1991–1995)Erste einfache Auszeichnungssprache für wissenschaftliche Dokumente am CERN.
HTML 4.01 (1999)Trennung von Struktur und Layout wird propagiert; CSS gewinnt an Bedeutung.
XHTML (2000)Strengere, XML-konforme Schreibweise von HTML; heute weitgehend abgelöst.
HTML5 (ab 2014 als W3C-Empfehlung)Semantische Elemente, native Formularvalidierung, Multimedia- und Storage-APIs ohne Plugins wie Flash.

3. Grundstruktur eines HTML-Dokuments

BestandteilBedeutung
<!DOCTYPE html>Kennzeichnet das Dokument als HTML5-Dokument und aktiviert den Standard-Rendering-Modus des Browsers.
<html>Wurzelelement des Dokuments; das lang-Attribut kennzeichnet die Dokumentsprache.
<head>Enthält Metadaten wie Zeichensatz, Titel, eingebundene Stylesheets und Skripte.
<body>Enthält den sichtbaren Inhalt der Seite.
<meta charset="UTF-8">Legt die Zeichenkodierung fest und verhindert Darstellungsfehler bei Sonderzeichen (z. B. Umlauten).

4. Semantik und wichtige Elemente

Element/AttributBedeutung
<div>Generischer Blockcontainer ohne eigene Semantik; dient der strukturellen Gruppierung.
<span>Generischer Inline-Container ohne eigene Semantik; dient der gezielten Formatierung einzelner Textabschnitte.
idEindeutiger Bezeichner eines Elements innerhalb des Dokuments; Zielanker für Verlinkungen sowie Ansatzpunkt für CSS und JavaScript.
classNicht eindeutiges Klassifizierungsmerkmal; mehrere Elemente können dieselbe Klasse tragen und gemeinsam gestaltet werden.
Semantische Elemente<header>, <nav>, <main>, <section>, <article>, <footer> beschreiben die Bedeutung von Seitenbereichen und verbessern Zugänglichkeit und Suchmaschinenlesbarkeit.

5. Formulare mit HTML5

FeatureBeschreibung
Neue Eingabetypenemail, number, date, tel, url u. a. ermöglichen passende mobile Tastaturen und Basisvalidierung ohne JavaScript.
Validierungsattributerequired, pattern, min/max und step definieren clientseitige Prüfregeln.
Constraint Validation APIJavaScript-Schnittstelle, über die Formularvalidierung programmatisch gesteuert und mit eigenen Fehlermeldungen versehen werden kann (siehe Kapitel „JavaScript“).
Platzhalter & Autofocusplaceholder und autofocus verbessern die Benutzerführung ohne zusätzlichen Skriptaufwand.

6. Das link-Element

AttributBedeutung
rel="stylesheet"Bindet ein externes CSS-Stylesheet ein (siehe Kapitel „CSS“).
rel="icon"Definiert das Favicon der Seite.
hrefPfad bzw. URL zur eingebundenen Ressource.
Bedeutung für die PerformanceExterne Stylesheets werden vom Browser parallel zum HTML geladen und können gecacht werden, was wiederholte Seitenaufrufe beschleunigt.

7. Neue Features von HTML5

FeatureBeschreibung
<canvas>Zeichenfläche für dynamische, JavaScript-gesteuerte 2D-Grafiken und Animationen.
<video> / <audio>Native Einbindung von Multimedia-Inhalten ohne Plugins wie Flash.
Web StoragelocalStorage und sessionStorage ermöglichen clientseitige Datenspeicherung ohne Cookies.
Geolocation APIErmittlung des Standorts eines Endgeräts mit Zustimmung des Nutzers.
Semantische StrukturSiehe Kapitel 4; erleichtert maschinelle Interpretation der Seite.

8. GET oder POST

MethodeMerkmalTypischer Einsatz
GETÜbermittelt Formulardaten als Teil der URL (Query-String); sichtbar, cachebar, in der Browser-Historie gespeichert.
POSTÜbermittelt Formulardaten im Nachrichtenkörper der HTTP-Anfrage; nicht in der URL sichtbar, nicht standardmäßig gecacht.
AuswahlkriteriumGET für idempotente, unkritische Abfragen (z. B. Suchanfragen); POST für Datenänderungen oder sensible Daten (z. B. Zugangsdaten, Patientendaten).

9. DOM und Browser-Rendering

AspektBeschreibung
ParsingDer Browser analysiert den empfangenen HTML-Code und erzeugt daraus eine Baumstruktur im Hauptspeicher – das Document Object Model (DOM).
Zugriff über JavaScriptÜber die DOM-Schnittstelle können Elemente ausgelesen, verändert, hinzugefügt oder entfernt werden (siehe Kapitel „JavaScript“).
CSS-ZuordnungFür jedes Element werden die zuständigen CSS-Regeln ermittelt und zu einem Render-Baum kombiniert.
RenderingEin Renderer berechnet Layout und Darstellung und zeichnet das Ergebnis auf den Bildschirm.

10. HTML in der Medizin-IT

AspektBeschreibung
Webbasierte ClientsModerne KIS- und PDMS-Systeme (siehe Kapitel „Gerätevernetzung“, Abschnitt 10) stellen ihre Benutzeroberfläche zunehmend als HTML-basierte Web-Clients bereit, die über den Webserver ausgeliefert werden.
Formulare für klinische DokumentationStrukturierte HTML5-Formulare mit Validierungsattributen unterstützen eine konsistente, fehlerarme Dateneingabe.
BarrierefreiheitSemantisches HTML erleichtert den Einsatz von Screenreadern und anderen Hilfsmitteln – relevant für Patientenportale.

11. Best Practices und Validierung

EmpfehlungBegründung
Semantische statt rein visuelle AuszeichnungErleichtert Wartbarkeit, Barrierefreiheit und maschinelle Verarbeitung.
Trennung von Struktur, Gestaltung und VerhaltenHTML für Struktur, CSS für Gestaltung, JavaScript für Verhalten – reduziert Kopplung und erleichtert Wartung.
W3C-ValidierungDer offizielle W3C-Validator prüft HTML-Dokumente auf Spezifikationskonformität und deckt strukturelle Fehler auf.
Verwendung der Browser-EntwicklertoolsErmöglichen die Inspektion des gerenderten DOM sowie das Debugging von Struktur- und Darstellungsproblemen.

12. Begriffe und Quellen

BegriffBedeutung
Element/TagGrundlegender Baustein eines HTML-Dokuments, z. B. <p>.
AttributZusätzliche Eigenschaft eines Elements, z. B. id oder class.
DOMDocument Object Model; Baumstruktur, über die der Browser Dokumentinhalte programmatisch zugänglich macht.
Semantisches HTMLVerwendung von Elementen entsprechend ihrer inhaltlichen Bedeutung statt nur ihrer visuellen Wirkung.
