1. Was ist JavaScript?

AspektBeschreibung
DefinitionJavaScript ist eine dynamisch typisierte, interpretierte Skriptsprache, die ursprünglich zur clientseitigen Steuerung von Webseiten entwickelt wurde und heute auch serverseitig (z. B. mit Node.js) eingesetzt wird.
StandardisierungDer Sprachstandard wird als ECMAScript (ES) durch die ECMA International gepflegt; aktuelle Engines unterstützen moderne Versionen wie ES6 (ES2015) und neuer.
Ausführung im BrowserEin in den Browser integrierter Interpreter (Engine) führt JavaScript-Code aus und ermöglicht den Zugriff auf HTML- und CSS-Inhalte über das DOM (siehe Kapitel „HTML“, Abschnitt 9).

2. Einbettung in HTML

MethodeBeschreibung
InlineDirekt über Attribute wie onclick am Element; heute aus Wartbarkeits- und Sicherheitsgründen nicht mehr empfohlen.
InternInnerhalb eines <script>-Blocks im HTML-Dokument.
ExternÜber <script src="datei.js"> eingebundene Datei; ermöglicht Wiederverwendung und Caching.
async / deferAttribute zur Steuerung des Ladeverhaltens externer Skripte: async lädt parallel und führt sofort aus, defer lädt parallel, führt aber erst nach vollständigem Parsen des HTML aus.

3. Wertetypen und Variablen

KonzeptBeschreibung
Primitive Wertetypenstring, number, boolean, undefined, null, symbol und bigint; werden bei Zuweisung kopiert (Value-Semantik).
HüllobjekteZu primitiven Typen existieren korrespondierende Objekttypen (z. B. String, Number), die zusätzliche Methoden bereitstellen.
varFunktionsgültiger Variablenbezeichner (älterer Standard); anfällig für unerwartetes Verhalten durch Hoisting.
letBlockgültige, veränderbare Variable; heutiger Standardfall für Variablen.
constBlockgültige Konstante; die Referenz kann nicht neu zugewiesen werden, der referenzierte Objektinhalt jedoch schon.

4. Gleichheit: == versus ===

OperatorVerhalten
==Vergleicht nach impliziter Typumwandlung; kann zu unerwarteten Ergebnissen führen (z. B. 0 == "0" ergibt true).
===Strikter Vergleich ohne Typumwandlung; sowohl Wert als auch Typ müssen übereinstimmen.
EmpfehlungIn produktivem Code sollte konsequent === verwendet werden, um Fehler durch implizite Typumwandlung zu vermeiden.

5. Arrays und Objekte

KonzeptBeschreibung
ArraysGeordnete, indexierte Listen von Werten beliebigen Typs mit zahlreichen eingebauten Methoden (map, filter, reduce u. a.).
Objekte ohne KlassenJavaScript-Objekte lassen sich als einfache Schlüssel-Wert-Sammlungen erzeugen, ohne dass zuvor eine Klasse definiert werden muss.
PrototypenJavaScript nutzt prototypische Vererbung: Jedes Objekt kann über eine interne Prototyp-Kette auf Eigenschaften und Methoden eines anderen Objekts zugreifen.
Klassen-Syntax (ES6)Die class-Syntax ist syntaktischer Zucker über dem prototypischen Vererbungsmodell und erleichtert die Lesbarkeit objektorientierten Codes.

6. Funktionen und Closures

KonzeptBeschreibung
Funktionsdeklarationfunction name() { }; wird vor der Ausführung vollständig eingelesen (Hoisting) und kann daher auch vor ihrer textuellen Position aufgerufen werden.
FunktionsausdruckZuweisung einer (auch anonymen) Funktion an eine Variable, z. B. const f = function() { } oder als Arrow Function const f = () => { }.
Innere Funktionen / ClosuresEine innerhalb einer Funktion definierte Funktion behält Zugriff auf die Variablen ihrer äußeren Funktion, auch nachdem diese beendet wurde – Grundlage für Kapselung und private Zustände.

7. this-Bindung

AufrufkontextWert von this
Methodenaufruf (obj.methode())Verweist auf das Objekt, über das die Methode aufgerufen wurde.
Einfacher FunktionsaufrufIm nicht-strikten Modus das globale Objekt, im Strict Mode undefined.
Arrow FunctionsÜbernehmen den this-Wert ihres umgebenden lexikalischen Kontexts, statt einen eigenen zu definieren – vermeidet einen häufigen Fehlerquell bei verschachtelten Callbacks.
Explizite BindungÜber call, apply oder bind kann der this-Kontext einer Funktion gezielt festgelegt werden.

8. Ereignisbehandlung

KonzeptBeschreibung
Event Listenerelement.addEventListener('click', handler) registriert eine Funktion, die beim Eintreten eines Ereignisses ausgeführt wird.
Event-ObjektEnthält Informationen zum ausgelösten Ereignis, z. B. das auslösende Element (target) oder gedrückte Tasten.
Event BubblingEreignisse propagieren vom auslösenden Element aus durch die Baumstruktur nach oben, sofern nicht explizit gestoppt (stopPropagation).
Event DelegationAusnutzung des Bubbling-Verhaltens, um einen einzigen Listener auf einem übergeordneten Element für viele Kindelemente zu verwenden – reduziert Speicherbedarf bei dynamisch erzeugten Listen.

9. Formularvalidierung mit der Constraint Validation API

AspektBeschreibung
GrundprinzipErgänzt die deklarativen HTML5-Validierungsattribute (siehe Kapitel „HTML“, Abschnitt 5) um eine programmatische JavaScript-Schnittstelle.
Wichtige MethodencheckValidity() prüft, ob ein Feld gültig ist; setCustomValidity() setzt eine eigene Fehlermeldung.
VorteilKombiniert native Browservalidierung mit individuellen, fachlich passenden Fehlermeldungen, z. B. bei klinischen Eingabeformularen.

10. Asynchrone Programmierung

KonzeptBeschreibung
CallbackEine Funktion, die als Argument übergeben und nach Abschluss einer asynchronen Operation aufgerufen wird; bei tiefer Verschachtelung entsteht die schwer lesbare „Callback-Hölle“.
PromiseObjekt, das den zukünftigen Abschluss (erfolgreich oder fehlerhaft) einer asynchronen Operation repräsentiert und mit .then()/.catch() verkettet werden kann.
async/awaitSyntaktischer Zucker über Promises, der asynchronen Code in einer sequenziell lesbaren Form schreiben lässt.
Bedeutung für Web-APIsGrundlage für AJAX- und REST-Aufrufe (siehe Kapitel „APIs“ und „REST“), die Netzwerkanfragen nicht-blockierend verarbeiten.

11. DOM-Manipulation

MethodeBeschreibung
document.querySelector()Selektiert das erste zu einem CSS-Selektor passende Element.
element.textContent / innerHTMLLiest bzw. setzt den Text- oder HTML-Inhalt eines Elements.
element.classListErmöglicht das Hinzufügen, Entfernen oder Umschalten von CSS-Klassen zur Laufzeit.
createElement / appendChildErzeugen und Einfügen neuer DOM-Elemente, z. B. zur dynamischen Darstellung von Listen oder Tabellenzeilen.

12. JavaScript in der Medizin-IT

AspektBeschreibung
Interaktive OberflächenJavaScript steuert dynamische PDMS-/KIS-Web-Clients, z. B. Live-Aktualisierung von Vitaldaten ohne vollständigen Seitenneuaufbau.
Clientseitige ValidierungSofortige Rückmeldung bei fehlerhaften Eingaben in klinischen Dokumentationsformularen, ergänzt durch serverseitige Prüfung.
Kommunikation mit Backend-SystemenAsynchrone Aufrufe (siehe Kapitel 10) an REST-/FHIR-Schnittstellen zum Laden und Speichern von Patientendaten, ohne die Seite neu zu laden.

13. Begriffe und Quellen

BegriffBedeutung
ClosureFunktion, die auf Variablen ihres umgebenden Gültigkeitsbereichs zugreifen kann, auch nach dessen Beendigung.
PromiseObjekt zur Repräsentation eines zukünftigen asynchronen Ergebnisses.
Event BubblingAufwärtspropagierung eines Ereignisses durch den DOM-Baum.
HoistingVerhalten, bei dem Deklarationen vor der Ausführung an den Anfang ihres Gültigkeitsbereichs „gehoben“ werden.
